Architecture

Three-Tier Network Stack

L1Settlement Layer

BNB Chain mainnet — OMC token issuance, staking smart contracts, DAO governance and final dispute arbitration.

L2Orchestration Layer

Dedicated L2 Rollup — high-frequency node heartbeats, task-allocation state mapping, state-channel settlements and low-cost micropayments.

GPUCompute Grid

Off-chain containerized grid — Docker/Kubernetes sandboxes with CUDA/ROCm acceleration, NVLink inter-GPU links and P2P data transport.

Workflow

Task Distribution & Matching

Every job is scored and routed by a weighted bipartite matching engine.

1

Task Lockup

Requesters lock OMC fee tokens in the escrow contract before dispatch.

2

Smart Scheduling

Nodes matched by VRAM, TFLOPS, bandwidth, latency & reputation score.

3

Sandbox Execution

Jobs run in isolated containers; outputs verified redundantly & via ZK proofs.
